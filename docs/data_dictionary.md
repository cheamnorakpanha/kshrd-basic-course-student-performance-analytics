# Data Dictionary

## Dataset

KSHRD Basic Course Student Performance Dataset

---

| Column | Data Type | Description |
|---------|-----------|-------------|
| Month | Categorical | Reporting month |
| Rank | Integer | Student's monthly rank |
| Student Name | String | Student full name |
| Gender | Categorical | Student gender |
| Class | Categorical | Student class |
| Project | String | Student project/team |
| Korean | Numeric | Korean language score |
| Attendance | Numeric | Attendance score |
| Scholarship | Numeric | Scholarship points |
| Korean Benefit | Numeric | Korean benefit points |
| Lunch | Numeric | Lunch score |
| PA | Numeric | PA score |
| Merit Score | Numeric | Merit score (M.S.) |
| Extra Activity | Numeric | Extra activity score |
| Total | Numeric | Overall monthly score |
| Comment | Categorical | Student status (CL, W, 2W, blank) |
